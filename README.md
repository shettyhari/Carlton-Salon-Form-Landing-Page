# Carlton Wellness Salon: Franchise Lead Form

Form-only landing page for Meta (Facebook / Instagram) ads. When someone taps the ad, the form
opens directly: contact details → three qualifying questions → thank-you screen.

## Folders

| Folder               | What's in it                                                                 |
|----------------------|------------------------------------------------------------------------------|
| `frontend/`          | The page: `index.html`, `config.js` (settings), `images/`, `favicon.png`     |
| `backend/`           | Node/Express server: serves the page and receives leads at `POST /api/leads` |
| `database/`          | Not connected yet. `database/README.md` lists the lead fields               |
| `deploy/`            | `build.js`, which creates the `release/` copies                              |
| `release/frontend/`  | Upload-ready static page (generated by `npm run build`)                      |
| `release/backend/`   | Upload-ready server with its own `package.json` (generated)                  |

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000 (set `PORT` to use another port). Submitted leads are validated and
printed in the server log.

## Connecting the database (developer)

Leads are **not stored** yet. Add the database code in `backend/leads.js` → `saveLead(lead)`.
The lead fields are listed in `database/README.md`. Nothing else needs to change.

## Settings

- **Meta Pixel ID:** `metaPixelId` in `frontend/config.js`, or the `META_PIXEL_ID` environment
  variable when the backend serves the page.
- **Where leads go:** when the backend serves the page, it posts to `/api/leads` automatically.
  If the page is hosted on its own (e.g. Vercel) and the backend lives elsewhere, set
  `formEndpoint` in `frontend/config.js` to the backend's full URL, e.g.
  `https://api.example.com/api/leads`, and allow that page's domain in the backend (CORS).
  While `formEndpoint` is `""`, the thank-you screen shows but leads are not sent anywhere.

## Deploy

```bash
npm run build
```

- `release/frontend/`: upload to any static host.
- `release/backend/`: run `npm install --omit=dev` then `npm start` on the server. It serves
  `release/frontend` alongside it.
- **Vercel:** `vercel.json` publishes `frontend/` as a static site (no backend there yet).
